# App móvil Comunidad

Cliente Expo inicial. Configurá `EXPO_PUBLIC_API_URL` con la URL HTTPS pública, por ejemplo `https://veterinaria.example.com/extraviados/api/v1`, y ejecutá `npm install` seguido de `npm start`.

En un teléfono real no uses `localhost`: debe apuntar al dominio HTTPS de la veterinaria.
